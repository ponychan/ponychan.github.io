    怎么算超平面：

    WX + b = 0

    W=（w1.... wn）是权重向量，n是属性个数，b是标量-bias

    落在超平面H1的训练元组就是支持向量

    ||w||欧几里得范数

    w/||w|| (X1-X2)=2/||w||

    最大边缘的计算公式，边缘为2/||w||

    分类器的复杂性由支持向量的个数决定，而不是数据的维度。

    支持向量数目可用于计算SVM分类器的期望误差上界，与数据维度无关。
