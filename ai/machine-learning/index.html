    0325-2 ROC曲线与PR曲线

    混淆矩阵

    真实\预测 0 1
    0 TN FP
    1 FN TP

    准确率accuracy：(TP+TN)/全部

    精确率precision：TP/ TP+FP 所有测出来的1里面，有多少是真的1

    TPR=True Positive Rate=TP / TP+FN 所有真实的1里面，被测为1的概率，=召回率

    FPR=False Negative Rate=FP / (FP+TN)=所有的0里面被误报为1的概率

    阈值

    阈值取0，即把所有都报成1

    0 1
    0 0 50
    1 0 50
