    the linux programming interface

    历史和标准

    Linux是UNIX操作系统家族的一个成员。在计算领域，UNIX有很长的历史

    两个关键事件：GNU项目和Linux内核

    vender小贩、卖主

    unix是很多机构组织一起开发的，导致了一些混乱，所以有了标准化。

    unix和C的历史

    unix的作者提出了几个概念，树状文件系统，单独的命令解释程序-shell，文件作为非结构化的字节流的概念notion

    1969，第一版unix

    1970用汇编重写了unix

    1973年C足够成熟到可以用来重写unix。这让后来移植到其他硬件架构成为可能

    genesis起源

    C的起源解释了为什么C被如此大规模的作为操作系统的编程语言。在C之前广泛使用的语言都是为了其他目的而设计的。Fortran是数学目的，cobol是商业处理。

    hitherto迄今

    C填补了迄今为止的空白。C和其他语言不一样的是，设计C语言的来源于几个为了相同的目标而努力的个人，这个目标就是开发一个高级语言来实现unix内核和相关的软件。C和unix都是为了专业的程序员自己而设计的。结果就是C语言小巧，高效，强大，模块化，设计的条理清晰

    unix到1979年已经声名鹊起，政府不允许商业使用，unix发行了好几个版本，并且给一些大学发放了license和内核的源代码

    unix分裂为BSD和systemV

    1983年BSD4.3包含了完整的TCP/IP实现，包括socket和一些tool

    AT&T被分拆以后政府允许卖UNIX授权了，所以AT&T分发了很多UNIX的license给商业公司，AT&T自己也在改进UNIX，发行了System V。因为大多数机器都采用UNIX系统，所以生态做起来了。

    Linux的历史

    叫Linux为操作系统是不恰当的，因为很多东西都来自于比Linux开始的更早的一个项目，GNU

    1984年，斯托曼，天才程序员，为MIT工作，开始试图创造一个free的unix实现。斯托曼的观点是道德的，free由法律所定义，而不是商业概念。

    1985年，FSF成立。GPL是关键的结果。GPL许可证下的代码必须可以获取源码，并且在GPL许可证下免费的再分发。修改自用——随意。再分发，必须在GPL许可证下。如果修改者的软件是以可执行格式分发的，那么修改者必须允许任何接收者可以用不超出一份拷贝的花费获取修改后的源码

    1989，第一版GPL诞生

    gnu一开始没有去做一个内核，而是做了很多其他软件。因为这些软件被设计为可以运行在unix like的操作系统上，所以可以被用在当时已经有的操作系统上，并且被移植到其他操作系统。GNU的作品有Emac编辑器、GCC、bash和glibc

    1990年代早期，GNU项目已经完成了除了内核之外的所有部分，开始设计基于Mach微内核设计新内核- HURD。但是hurd离投入使用非常遥远。万事俱备，就差内核了。

    1991年Linus学习了minix操作系统，想给自己的80386电脑写一个操作系统。用几个月的时间写了一个操作系统。并在10月5号发布了0.02版本。根据传统，类unix的名字以X结尾，所以内核被命名为Linux。最初用的是别的许可证，但是不久Linus就改用了GPL许可证。请求援助是有效的。其他的程序员加入进来帮助开发Linux，不久就添加了许多新的特性，比如改进文件系统，网络支持，设备驱动，多核支持。到1994年3月，发布了1.0版本，1995年3月2.0版本。

    标准化

    1980年代，unix的分支以及各个厂商都做出了很多各自的修改，给标准化工作带来了很大压力

    C语言的标准化

    78年K&R C标准，很多地方写的不清楚，85年C++出现。89年 ANSI C出现定义了语法和语义，描述了C标准库的行为。后来又发展出了C99.

    C的实现是独立于任何操作系统的细节的，不依赖于unix 操作系统，也就是说仅使用了C库的程序可以被移植到任何提供了C实现的操作系统和计算机上。

    POSIX 标准

    IEEE的可移植应用标准协会PASC在推动源代码级别的可移植应用。POSIXrefer了这个PASC的许多标准。

    POSIX1基于unix系统调用和C库函数API，但是不要求跟接口相关的任何特定的实现，也就是接口可以被任何操作系统实现，而不仅仅是unix。

    POSIX2对shell和unix的许多工具例如C编译器的命令行结构做出了标准

    FIPS联邦信息处理标准，美国政府买电脑的标准

    SUS标准

    开放软件基金会

    Linux，标准和Linux标准base

    各发行版之间有不同，所以用了一个Linux standard Base来确保二进制程序能通用。
