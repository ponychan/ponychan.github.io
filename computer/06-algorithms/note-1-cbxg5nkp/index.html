    研究对象的特性和对象间的关系

    数据结构是一门研究非数值计算的程序设计问题中计算机的操作对象以及它们之间的关系和操作等等学科

    数据：对客观事物的符号表示

    数据元素：数据的基本单位

    数据对象：性质相同的数据元素的集合，是数据的一个子集

    数据结构：相互之间存在一种或者多种特定关系的数据元素的集合

    集合、线性结构、树形结构、图状结构或网状结构

    定义：数据结构=（D，S） D是数据元素的有限集，S是D上关系的有限集

    逻辑结构：数据元素之间的关系（集合关系、一对一的线性关系，一对多的树形关系，多对多的网状/图形关系）

    物理结构：包括了数据元素的表示和关系的表示（顺序存储、链式存储、索引存储、散列存储）

    算法的设计取决于逻辑结构、实现取决于物理结构

    C语言中的数据类型就是一个值的集合和定义在这个值集上的一组操作的总称。

    数据类型分为原子类型和结构类型

    6.2二叉树

    每个结点至多只有两棵子树，且子树分左右

    二叉树性质：

    1. 第i层至多有2的i-1次方个结点，i大于等于1
    2. 深度为k的二叉树最大结点数为2的k次方-1
    3. 终端结点数为n0，度为2的结点数为n2，则n0=n2+1

    根据性质2，深度为k且有2的k次方-1个结点的二叉树称为满二叉树

    完全二叉树就是满二叉树去掉最后一层的几个叶子结点。

    完全二叉树的叶子结点只在最后两层取到。

    1. n个结点的完全二叉树的深度为（log2n）+1（向下取整）
    2. n个结点的完全二叉树的结点按层编号，则对任一结点i，

    如果i=1，则结点i是二叉树的根，如果i>1，则双亲是i/2向下取整

    如果2i>n，则i无左孩子。如果2i<=n，则左孩子是2i

    如果2i+1>n，则i无右孩子。如果2i+1<=n，则右孩子是2i+1

    所有结点的左子树编号都是自己的2倍，右子树编号为2倍加1

    // 直接插入排序
void simpleinsert(int array[], int length)
{
  for (int i = 1; i < length; i++)
  {
    if (array[i] > array[i - 1])
    {
      continue;
    }
    else
    {
      for (int j = 0; j < i; j++)
      {
        if (array[j] > array[i])
        {
          int temp = array[i];
          for (int k = i; k >= j; k--)
          {
            array[k] = array[k - 1];
          }
          array[j] = temp;
          break;
        }
      }
    }
  }
}

    冒泡排序

    void bubblesort(int array[], int length)
{
  bool flag;
  // 初试序列完全逆序时，需要length趟完成交换。非完全逆序时，小于length趟完成交换。判断本趟未发生交换时提前结束排序
  for (int i = 0; i < length; i++)
  {
    // 交换标记
    flag = true;
    // 待排序序列是0到length-i-1这部分，length-i-1到length-1这部分在前期已经有序
    for (int j = 0; j < length - i - 1; j++)
    {
      // 进行swap并修改swap标记
      if (array[j] > array[j + 1])
      {
        int temp = array[j];
        array[j] = array[j + 1];
        array[j + 1] = temp;
        flag = false;
      }
    }
    // 一趟排序结束，判断是否发生交换，未发生交换证明排序结束
    if (flag == true)
    {
      break;
    }
  }
}

    数据结构是一门研究非数值计算的程序设计问题中计算机的操作对象以及它们之间的关系和操作等的学科。

    数据

    数据元素

    数据对象

    数据结构是相互之间存在一种或多种特定关系的数据元素的集合。不同数据元素相互之间的关系称为结构。四类基本结构包括：集合、线性结构、树形结构、图状结构或网状结构。数据结构是一个二元组Data_Structure=（D，S） D是数据元素的有限集，S是D上关系的有限集

    逻辑结构：结构定义中的中的关系描述的是数据元素之间的逻辑关系

    物理结构：数据结构在计算机中的表示/映像，称为数据的物理结构

    数据元素之间的关系在计算机中的两种不同表示方法——顺序映像和非顺序映像得到两种不同的存储结构：顺序存储结构和链式存储结构

    数据类型：一个值的集合和定义在这个值集上的一组操作的总称

    值：非结构的原子类型/结构类型

    抽象数据类型ADT：一个数学模型以及定义在该数学模型上的一组操作

    一个软件系统的框架应该建立在数据之上而非建立在操作上。在每个模块定义一组数据和施于这些数据上的一组操作。通常包含定义、表示、实现3个部分

    抽象数据类型（D，S，P）三元组表示D数据、S是D上的关系集、P是对D的基本操作集。

    算法：有穷性、确定性、可行性、输入、输出

    算法设计的要求：正确性、可读性、健壮性、效率与低存储量需求

    第2章 线性表

    线性表：n个数据元素的有限序列。同一线性表中的元素必定具有相同特性

    文件包含大量数据元素（记录）、数据元素包含若干个数据项

    线性表的顺序表示：若干个一组地址连续的存储单元依次存储线性表的数据元素。若逻辑位置相邻，则物理位置也相邻。LOC（Ai）=LOC（A1）+（i-1）*l

    线性表的链式表示和实现用一组任意的存储单元存储线性表的数据元素。数据元素Ai包含本身的信息和其直接后继的信息，它的存储映像称为结点。节点包含数据域和指针域，指针域存储的信息称作指针或链。又称为线性链表或单链表。整个链表的存取必须从头指针开始进行，最后一个结点的指针域为空NULL单链表可由头指针唯一确定。

    第3章 栈和队列

    栈和队列的基本操作是线性表操作的子集，所以栈和队列也是线性表

    栈：限定仅在表尾进行插入或删除操作的线性表。表尾称为栈顶，表头称为栈底。不含元素的空表称为空栈。特点：后进先出LIFO

    栈的应用：调用子函数、中断恢复现场、递归调用

    队列：限定在表的一端进行插入，另一端删除。允许插入的一端叫做队尾，允许删除的一端称为队头。特点：先进先出FIFO

    队列的应用：通信、缓冲

    第6章 树和二叉树

    树：n（n>0）个结点的有限集。在一棵非空子树中：1.有且仅有一个特定的被称为根的结点。2.当n>1时，其余结点可分为m（m>0）个互不相交的有限集，其中每一个集合本身又是一棵树，称为根的子树。

    树的结点：包含一个数据元素及若干指向其子树的分支。

    度：结点拥有的子树数

    终端结点（叶子）：度为0的结点

    非终端节点（分支结点）：度不为0的结点

    树的度：树内各结点度的最大值

    结点的子树的根称为该结点的孩子；结点称为孩子的双亲；同一个双亲的孩子之间称兄弟。结点的祖先是从根到该结点所经分支上的所有结点。以某结点为根的子树中的任一结点都称为该结点的子孙

    结点的层次：从根开始定义起，根为第一层，根的孩子为第二层。双亲在同一层的结点互为堂兄弟。树中结点的最大层次称为树的深度。

    如果树中结点的各子树从左到右是有次序的，称该树为有序树，否则称为无序树。

    森林是m棵互不相交的树的集合。

    二叉树：每个结点至多只有两棵子树，并且有左右之分

    二叉树的性质：

    1在二叉树的第i层上至多有2的i-1次方个结点i>=1

    2深度为k的二叉树至多有2的k-1个结点。k>=1

    3对任意一棵二叉树T，如果其终端结点数为n0，度为2的结点数为n2，则n0=n2+1

    证明：

    n=n0+n1+n2

    n=B+1 B=n1+2n2

    n=n1+2n2+1

    4具有n个结点的完全二叉树的深度为[log2 n]+1

    5如果对一棵有n个结点的完全二叉树的结点按层次编号，则对任一结点i有

    （1）如果i=1，则结点i是二叉树的根，无双亲，如果i>1，则其双亲PARENT（i）是结点i/2

    （2）如果2i>n，则结点i无左孩子（结点i为叶子结点）；否则其左孩子是结点2i

    （3）如果2i+1>n，则结点i无右孩子；否则其右孩子RCHILD（i）是结点2i+1

    满二叉树：一棵深度为k且有2的k-1次方个结点的二叉树

    完全二叉树：深度为k，有n个结点的二叉树，当且仅当其每一个结点都与深度为k的满二叉树中编号为1-n的的结点一一对应

    遍历二叉树：先序，中序，后序

    图中的数据元素通常称作定点，V是定点的有穷非空集合；VR是两个顶点之间的关系的集合。若属于VR，则表示从v到w的一条弧，且称v为弧尾或初始点；称w为弧头或终端点，此时的图称为有向图，若属于R，必有属于VR，则以无序对(v,w)代替这两个有序对，表示v和w的一条边，此时的图称为无向图

    用n表示图中的顶点数，v表示边或弧的数目。

    对于无向图，e的取值范围是从0到1/2n(n-1)，有1/2n(n-1)条边的无向图称为完全图

    对于有向图，e的取值范围是从0到n(n-1)，具有n(n-1)条弧的有向图称为有向完全图

    带权的图通常称为网

    e<nlogn是稀疏图，否则为稠密图

    连通图：无向图中任意两个顶点之间都存在路径

    连通分量：无向图中的极大连通子图

    强连通图：有向图中每一对定点从A到B和从B到A都存在路径

    强连通分量：有向图中的极大强连通子图

    一个连通图的最小生成树是一个极小连通子图，含有全部顶点和足以构成一棵树的n-1条边

    一棵有n个顶点的生成树有且仅有n-1条边，边数少于n-1，则是非连通图，多于n-1，则必定有环。但是有n-1条边的图不一定是生成树

    如果一个有向图恰有一个顶点的入度为0，其余顶点的入度均为1，则是一棵有向树。一个有向图的生成森林由若干棵有向树组成，含有图中全部顶点，但是只有足以构成若干棵不相交的有向树的弧。
