    研究对象的特性和对象间的关系

    数据结构是一门研究非数值计算的程序设计问题中计算机的操作对象以及它们之间的关系和操作等等学科

    数据：对客观事物的符号表示

    数据元素：数据的基本单位

    数据对象：性质相同的数据元素的集合，是数据的一个子集

    数据结构：相互之间存在一种或者多种特定关系的数据元素的集合

    集合、线性结构、树形结构、图状结构或网状结构

    定义：数据结构=（D，S） D是数据元素的有限集，S是D上关系的有限集

    逻辑结构：数据元素之间的关系（集合关系、一对一的线性关系，一对多的树形关系，多对多的网状/图形关系）

    物理结构：包括了数据元素的表示和关系的表示（顺序存储、链式存储、索引存储、散列存储）

    算法的设计取决于逻辑结构、实现取决于物理结构

    C语言中的数据类型就是一个值的集合和定义在这个值集上的一组操作的总称。

    6.2二叉树

    每个结点至多只有两棵子树，且子树分左右

    二叉树性质：

    1. 第i层至多有2的i-1次方个结点，i大于等于1
    2. 深度为k的二叉树最大结点数为2的k次方-1
    3. 终端结点数为n0，度为2的结点数为n2，则n0=n2+1

    根据性质2，深度为k且有2的k次方-1个结点的二叉树称为满二叉树

    完全二叉树就是满二叉树去掉最后一层的几个叶子结点。

    完全二叉树的叶子结点只在最后两层取到。

    1. n个结点的完全二叉树的深度为（log2n）+1（向下取整）
    2. n个结点的完全二叉树的结点按层编号，则对任一结点i，

    如果i=1，则结点i是二叉树的根，如果i>1，则双亲是i/2向下取整

    如果2i>n，则i无左孩子。如果2i<=n，则左孩子是2i

    如果2i+1>n，则i无右孩子。如果2i+1<=n，则右孩子是2i+1

    所有结点的左子树编号都是自己的2倍，右子树编号为2倍加1

    森林转二叉树规则：

    F={T1,T2,,,Tm}是森林，按照如下规则转化成二叉树B={root,LB,RB}

    1. 若F为空，即m=0，则B为空树
    2. 若F非空，即m!=0，则T1的根即为二叉树的根；B的左子树，是把T1去掉根之后形成的森林转换成二叉树。B的右子树，是F去掉T1后形成的森林转换成二叉树

    强连通图的一个定理：一个有向图是强连通的，当且仅当G中有一个回路，它至少包含每个节点一次。

    （1）充分性：如果G中有一个回路，它至少包含每个节点一次，则G中任两个节点都是互相可达的，故G是强连通图。

    （2）必要性：如果有向图是强连通的，则任两个节点都是相互可达。故必可做一回路经过图中所有各点。若不然则必有一回路不包含某一结点v，并且v与回路上的个节点就不是相互可达，与强连通条件矛盾。

    深度优先遍历 （DFS）：从第一个顶点开始，未访问则打印并赋值已访问，之后检查其二维数组（二维数组储存顶点与顶点是否有关，有关为1，无关为0），碰到与其相关的第一个顶点，递归调用此函数，不断往下走，直到碰到结尾或已访问的顶点，之后就发挥了递归的不断回调，依次检测其它边关系。

    广度优先遍历（BFS）：大循环嵌套小循环结构：大循环从顶点数组里的第一个开始往后访问，碰到未访问的顶点进入小循环，直到循环到最后一个顶点结构。小循环里接收大循环循环到的顶点，将顶点出队并打印，然后遍历此顶点的二维数组（二维数组储存顶点与顶点是否有关，有关为1，无关为0），若碰到组成边的有关顶点，入队。全部遍历后回到小循环，小循环全部遍历后，回到大循环，如此运行下去。

    prim算法（普里姆算法，侧重点顶点）：（思想：从一顶点开始，比较与此顶点相连的路径大小，取最小，然后顺最小路径到达下一结点，再寻找，且要判断是否和以往的顶点构成回路，然后下一个，以此类推，遍历整个图的顶点）

    Kruskal算法（克鲁斯卡尔算法，侧重点边）：（思想：统计所有路径，循环选出剩余路径中最短的路且判断所选路径是否和之前选择的路径构成回路，最终连接整个图的顶点）

    bool FindTree(VertexData u, VertexData v,vector<vector > &Tree)

    {

    unsigned int index_u = INFINITE;

unsigned int index_v = INFINITE;

for (unsigned int i = 0; i < Tree.size();i++)      //检查u,v分别属于哪颗树

{

    if (find(Tree[i].begin(), Tree[i].end(), u) != Tree[i].end())//！=说明begin到end间有要查找的值

        index_u = i;

    if (find(Tree[i].begin(), Tree[i].end(), v) != Tree[i].end())//！=说明begin到end间有要查找的值

        index_v = i;

}



if (index_u != index_v)                          //u,v不在一颗树上，合并两颗树

{

    for (unsigned int i = 0; i < Tree[index_v].size();i++)

    {

        Tree[index_u].push_back(Tree[index_v][i]);  //将第二棵树的所有顶点加到第一颗树上

    }

    Tree[index_v].clear();                       //清空第二棵树

    return true;

}

return false;

    }

    Dijkstra算法（迪杰斯特拉算法，目的求两点间最短路径）：

    从某一个顶点开始，选取与它连接的最短路径，然后到选取的路径的另一顶点，选取与之前路径相加后长度最短的路径，但此时的长度要和之前的顶点的其他路径长度作比较，选最短者，如此反复，直到到目的顶点。

    代码思路：一数组用于保存1或0，表示是否寻找到最短路径，一数组用于保存最短路径。

    开始一for循环寻求距离v(0)最近的顶点v(1)，保留其距离到min变量中，然后另一for循环，用于更改其它与v(0)连接的顶点到v(0)的距离，方法为检测v(1)与其之间的距离加上min(v(1)到v(0))是否小于v(0)直接到它的距离，若小于则更换，否则不更换，以下为样例代码：

    Floyd算法（弗洛伊德算法，求所有顶点到其他所有顶点的最短路径）算法结束后，数组保存了所有任意两点间的最短距离

    思路：第一步：数组保存所有两点间直接连接的距离;第二步，数组保存所有两点间只有一个其他点的连接距离，但是是在比直接连接的距离小的前提下，否则值不变;如此反复下去，最终两点间的距离为最短距离（两点间可能含有n个点,n>=0）。

    创建两个数组：D[vi][vj],P[vi][vj]。D数组作用是储存vi结点与vj结点间的距离（运算后储存最短距离）P数组作用是储存vi结点与vj结点间的路径信息，例：假如P(5,1)=3则说明从V5到V1经过V3，路径为{V5,V3,V1}，如果P(5,3)=3，说明V5与V3直接相连，如果P(3,1)=1，说明V3与V1直接相连。
