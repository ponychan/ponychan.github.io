    数据库分为关系型数据库和非关系型数据库

    绪论

    • 1.1 数据库基本概念 ：数据、数据库、数据库管理系统、数据库系统的定义与特点。
    • 1.2 数据库系统结构 ：三级模式结构（外模式、概念模式、内模式）及二级映像（外模式 / 概念模式映像、概念模式 / 内模式映像），多级结构的优点。
    • 1.3 数据模型 ：概念数据模型（E-R 模型，包括实体、属性、联系等概念及 E-R 图的绘制），逻辑数据模型（关系模型、网状模型、层次模型等，重点介绍关系模型的基本概念如关系、元组、属性、域、主键、外键等）。

    数据库系统概述

    数据——描述事物的符号记录，具有语义

    数据库——冗余、独立性、可扩展性

    数据库管理系统

    数据库系统DBS：DB、DBMS、APP、DBA

    人工阶段：数据不共享、不独立于应用程序，

    文件系统阶段：数据共享性弱，冗余度高，独立性弱

    数据库系统阶段：数据结构化、共享性强、冗余度低、易于扩充

    数据独立性强-逻辑独立性、物理独立性——两级映像

    数据统一由数据库管理系统管理控制。安全、完整、并发、恢复

    第一章 数据库基础

    第二章 关系数据库

    第三章 数据库设计

    • 3.1 数据库设计概述 ：数据库设计的目标与步骤（需求分析、概念结构设计、逻辑结构设计、物理结构设计、数据库实施、数据库运行与维护）。
    • 3.2 概念结构设计 ：概念结构设计的方法与步骤，如自顶向下、自底向上、逐步扩张等方法，E-R 图的合并与优化。
    • 3.3 逻辑结构设计 ：将 E-R 图转换为关系模型的方法，关系模型的优化（范式理论，包括 1NF、2NF、3NF、BCNF 的定义与判断，模式分解的方法与步骤）。

    第四章 数据库管理系统

    • 4.1 DBMS 的总体结构 ：DBMS 的功能模块划分（存储管理器、查询处理器、事务管理器、数据库定义语言与数据库存取语言翻译器等），各模块的主要功能与协作关系。
    • 4.2 存储管理 ：数据库的存储结构（数据库在磁盘上的存储方式，如堆文件、排序文件等），缓冲区管理（缓冲区的作用、缓冲区管理策略如 LRU 替换策略等）。
    • 4.3 查询处理与优化 ：查询处理的过程（词法分析、语法分析、查询优化等），查询优化的目标与策略（如选择运算的下推、连接顺序的优化等）。

    第五章 事务管理

    • 5.1 事务的概念与性质 ：事务的定义，事务的特点（原子性、一致性、隔离性、持久性）。
    • 5.2 并发控制 ：并发操作带来的问题（丢失修改、脏读、不可重复读、死锁等），并发控制的方法（封锁机制，包括排他锁、共享锁、意向锁等，封锁协议的级别与优缺点；乐观控制法与悲观控制法的概念与区别）。
    • 5.3 数据库恢复技术 ：数据库故障的类型（事务故障、系统故障、介质故障），恢复的实现技术（数据转储、日志记录、数据库镜像等），恢复策略（事务故障的恢复、系统故障的恢复、介质故障的恢复）。
